
# 🏠 House Price Prediction Using Machine Learning

## Project Description
House Price Prediction is a Machine Learning project
that predicts the estimated selling price of a house
based on property features such as area, bedrooms,
bathrooms, parking, stories and furnishing status.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Linear Regression
- Streamlit
- Joblib

## Machine Learning Algorithm
Linear Regression

## Project Structure

House-Price-Prediction/
- app.py
- train_model.py
- Housing.csv
- house_price_model.pkl
- requirements.txt
- README.md

## Installation

Install the required libraries:

pip install -r requirements.txt

## Model Training

Run the following command:

python train_model.py

This will train the model and generate
house_price_model.pkl.

## Run Application

streamlit run app.py

## Model Evaluation
The model is evaluated using:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R2 Score

## Project Objective
To estimate house prices using Machine Learning
and understand how different property features
influence house values.
